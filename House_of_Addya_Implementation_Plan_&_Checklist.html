Developer Checklist: What You Need To Do From Your Side

Action items before client handover
Phase 1 Admin Passkey & Security Setup
⏱ 2 mins
  • Admin Security & Passkey Configured: Passkey defaults securely to 5692 (or custom NEXT_PUBLIC_ADMIN_PIN in .env.local). Demo bypass button automatically hides when custom PIN is active.
  • Verify PIN Gate: Open http://localhost:3000/admin in an incognito window and verify the passkey unlocks the dashboard cleanly.
  • Test Lock Mechanism: Click the Lock icon in the header to confirm the session is destroyed from sessionStorage.
💡 Pro Tip: Addya can bookmark https://houseofaddya.com/admin?pin=XXXX on her iPhone Safari for instant 1-tap entry without typing every time!
Phase 2 Cloud Database Setup (Supabase Free Tier)
⏱ 5 mins
  • Create Supabase Project: Go to supabase.com → New Project → Name: house-of-addya → Region: Mumbai (ap-south-1).
  • Execute SQL Schema: Open SQL Editor in Supabase, copy the contents of supabase/schema.sql, and click Run. Creates tables: products, site_settings, orders, coupons, and reviews.
  • Configure API Keys in .env.local: Copy Project URL and anon public key into NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY.
Phase 3 Payment Gateway Registration (Razorpay & Direct UPI)
⏱ 5 mins
  • Create Razorpay Account: Register at razorpay.com using Addya's business email and bank details for automated daily settlement.
  • Generate API Keys: Under Settings → API Keys, generate Key ID and Key Secret. Add NEXT_PUBLIC_RAZORPAY_KEY_ID to .env.local.
  • Official UPI & Settlement Bank Configured: Merchant UPI VPA is active as anmoldube93@okhdfcbank with direct settlement to Punjab National Bank (A/C: 0781100100005018, IFSC: PUNB0078110, Beneficiary: Anmol Dubey). Direct 0% commission!
Phase 4 Courier Logistics Setup (Shiprocket Express)
⏱ 5 mins
  • Create Shiprocket Account: Register at shiprocket.in and enter Atelier pickup hub address in New Delhi.
  • Initial Wallet Recharge: Add ₹500 to the shipping wallet for initial label printing (Delhivery, BlueDart, BlrExpress).
  • Verify Live Tracking: In /admin under Orders, update an order status to "Shipped" and enter a tracking number. Visit /track to verify the status pills update properly.
Phase 5 Custom Domain & Free Cloud Hosting (Vercel)
⏱ 10 mins
  • Push Repository to GitHub: Ensure latest changes are committed: git add . && git commit -m "Production release" && git push.
  • Deploy on Vercel: Import the repo at vercel.com (Hobby Tier — $0/month). Add environment variables: NEXT_PUBLIC_ADMIN_PIN, NEXT_PUBLIC_RAZORPAY_KEY_ID. Hit Deploy.
  • Point Custom Domain: Under Vercel Project Settings → Domains, add houseofaddya.com. In the domain registrar (GoDaddy, Namecheap, Hostinger):
    • Add A Record: @ → 76.76.21.21
    • Add CNAME Record: www → cname.vercel-dns.com
  • Verify Automatic SSL: Confirm HTTPS certificate is generated and green padlock shows on https://houseofaddya.com.
Phase 6 Store Settings & Business Information Review
⏱ 3 mins
  • Update WhatsApp Number: In /admin Store Settings, input Addya's official customer care WhatsApp number for the floating concierge widget.
  • Verify GSTIN & Business Address: Check Atelier address and return logistics address.
  • Review Promo Coupons: In /admin Coupons, ensure launch codes ADDYA10 (10% off) and FREESHIP are active.
Phase 7 Pre-Handover End-to-End QA Testing
⏱ 5 mins
  • Mock Order Checkout: Select an outfit piece → pick size & color → add to cart → proceed to checkout → submit simulated UPI order → verify confetti burst and order confirmation ID.
  • Mobile Responsiveness Check: Open storefront and /admin on iPhone and Android browsers to confirm buttery-smooth touch interactions.
  • Self-Service Catalog Test: In /admin, add a test piece, adjust its stock by +5, and delete it to verify the real-time reactivity.
